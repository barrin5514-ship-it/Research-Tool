# Collection exclusions and visual-reference skips — October 25, 2026

**My library → Excluded collections** controls which collections are skipped. Reference is excluded by default, using case-insensitive names with surrounding spaces ignored. Unchecking it persists across restarts. Any excluded membership excludes the post, even when the post belongs to another included collection. Every post remains in SQLite; this feature does not delete posts or existing results.

Excluded collections are removed from batch choices. Both matched Project ideas and New ideas omit excluded posts and classified visual references. Excluded names are also hidden from the library sidebar, and excluded posts are hidden from the normal All/library view. They remain accessible in Excluded collections settings and the collapsed Skipped list. Sidebar counts include only visible posts. Normal batch selection, the server's pre-download gate, the pre-DeepSeek gate, and project rechecks all enforce the policy. If a collection is excluded during active work, an already-started download cannot be undone, but the next paid analysis and subsequent downloads are gated by the current settings. Completed attempts wait twenty seconds as before.

**Skipped** is a collapsed list showing ten posts at a time with a Show 10 more button. It includes collection exclusions and actual “Skipped: visual reference” classifications. **Not reference — analyze it** records an individual exception and starts one video when idle; if other work is active, it queues that post for a later batch instead. This does not include the rest of its collection. The exception bypasses collection exclusions and prevents the visual-reference classifier from skipping that same post again. The normal analysis may still return no useful recommendations. It is a normal research action, potentially using one paid DeepSeek call.

The existing text-only DeepSeek request now includes the already-saved caption, transcript and OCR. It also requests content type and a reason. Clear text evidence of posing/modeling without tools, techniques, code or how-to material can produce a visual-reference skip in that same call, with no recommendations. No extra model call or image-based classifier is used. Silence, missing text, a person appearing, fashion, beauty or fitness alone is insufficient; tutorials and uncertainty stay eligible. Code also refuses a skip without usable source text/caption and a nonempty reason. Usage is still recorded for the single analysis call. Real-world classification quality has not been tested in this task and remains fallible; the override is available for mistakes.

Visual-reference classifications are stored as skipped. If an older result is replaced by this classification, its original result JSON is retained in reference_history. Nothing is deleted. Exclusion-only skips do not require changing all existing rows: the dashboard derives them from collection membership and settings. Including a collection makes its waiting posts eligible again; posts skipped solely because the collection changed during processing are returned to waiting when no exclusion remains.

The dashboard displays excluded posts and Left to research. These omit test fixtures. Left to research counts non-excluded/non-reference waiting, retrying and failed items, plus incomplete results without answer sections; failed/incomplete items may still need the existing retry control.
