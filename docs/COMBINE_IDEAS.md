# Combine ideas — October 25, 2026

Each project group has **Combine ideas**, enabled when at least two distinct analyzed videos have saved recommendations for that project. Test fixtures, excluded collections and visual references are omitted. Keyword-only evidence fallback records do not qualify as analyzed results. Existing DeepSeek and actual local-vision analyses do qualify; videos with no supported project recommendation do not count just because their collection has the same name.

Click Combine ideas to see the result count and a conservative upper estimate. No model request runs until **Confirm combine** is clicked. Previews expire after ten minutes, are single-use and are rejected if the project or saved input changes. Normal video batches, rechecks and combining cannot run concurrently. Existing batch controls retain their cap-free behavior; the separate confirmation applies to combining because it is explicitly requested for this feature.

The new separate text adapter sends one request to the fixed official DeepSeek chat-completions endpoint. It includes the project name, video IDs for attribution, the existing short summary (up to 260 characters) and saved project recommendations only. No transcript, OCR, caption, title, media, image, external project files or project description is sent. No download, transcription or source browsing is performed. Input over 400,000 bytes is refused before a paid call. Cost estimates use the existing conservative rates and a maximum 1,800 output tokens; estimates are not invoices.

The response must contain two to four plans. Each has a name, at least two real source-video IDs, two to three short plain-English bullets, an explanation of how the ideas work together, and a first step. Invalid IDs, malformed output and invalid bullets are rejected. All accepted plans are marked NOT VERIFIED by the server, regardless of model claims. Known usage is logged before plan validation; failed requests are logged with unknown usage and are never automatically retried.

Dated plan sets are saved in SQLite project_combinations. Original video results are untouched. Project ideas shows the newest set with source links, bullets first and longer explanations under Give me more. Dates use America/New_York. Expansion survives polling. Earlier sets are retained under Earlier combined plans. Plans using results that become excluded or stop matching are hidden rather than deleted.

After new matches arrive, **Refresh** opens the same count/cost confirmation using the latest notes. Refresh creates a new dated set and keeps earlier sets. Failed refreshes preserve the earlier plans. The global spending tracker includes combination calls and costs while keeping its videos-analyzed count separate.
